Command line

Phoenix can render and convert documents without showing a window, so you can script batch exports and render on a build machine.

On Windows, the program is Phoenix.exe in the folder Phoenix was installed to. On macOS, it is /Applications/Phoenix.app/Contents/MacOS/Phoenix. The examples below just say Phoenix.

Open a file

Phoenix drawing.fla

Starts Phoenix with the file open, the same as dropping it on the program.

Export a movie

Phoenix --export-movie scene.fla out.mp4
Phoenix --export-movie scene.fla frames.png
Phoenix --export-movie scene.fla loop.gif
Phoenix --export-movie scene.fla soundtrack.wav

Renders every frame and exits. The output name decides the format:

Output ends inMakes
.pngA PNG sequence: frames0001.png, frames0002.png and so on
.gifAn animated GIF
.wavThe soundtrack
anything elseH.264 video, for example .mp4 or .mov, with sound

Add --per-layer after the output name to write a separate PNG sequence for each layer:

Phoenix --export-movie scene.fla layers.png --per-layer

Export an image

Phoenix --export-image scene.fla poster.png --frame 48 --size 1920x1080 --matte transparent
OptionMeaning
--frame NThe frame to render, counting from 1. The default is the first frame.
--size WxHThe output size in pixels.
--matte transparent or --matte COLORThe background. A color can be a name or a hex value such as #202020.
--quality 0-100JPEG quality.

The format comes from the output name: .png, .jpg or .gif.

Convert between formats

Phoenix --convert scene.fla scene.phx
Phoenix --convert scene.phx scene.fla
Phoenix --convert scene.fla scene_xfl

Converts between Phoenix documents, FLA files and XFL folders. A name ending in .phx or .fla chooses that format; any other name makes an XFL folder. If something in the document cannot be written to the chosen format, Phoenix lists it after Not written:.

Inspect a Phoenix document

Phoenix --phx-dump scene.phx

Prints the parts of a .phx file as text, which is useful when reporting a problem with a file.

Running on a machine without a display

Exports never show a window. On a server or build agent with no display at all, set the environment variable QT_QPA_PLATFORM=offscreen so Phoenix doesn't look for one:

QT_QPA_PLATFORM=offscreen Phoenix --export-movie scene.fla out.mp4

On Windows, Phoenix finds the system fonts by itself in this mode, so text renders normally.

Exit codes are 0 on success and non-zero on failure, with the reason printed, so scripts can stop on errors.
