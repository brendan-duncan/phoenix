Settings and preferences

Phoenix remembers the choices you make as you work, and you change most settings where you use them. A few general ones are in the Preferences dialog, and every key can be changed in Keyboard Shortcuts.

Preferences

Choose Edit › Preferences (Ctrl+U):

Undo levels
How many steps Edit › Undo can go back, 200 unless you change it. The oldest steps are let go as new ones come; No limit keeps them all, at the cost of memory.
Auto-recovery
How often a recovery copy of unsaved work is written, or Off. The same setting as File › Auto-Save.
At startup
Whether the start screen appears.
Highlight
A selection is outlined in its layer's color, or in one color you choose.
Click accuracy
How near a click must be to a line or a point to pick it: Strict, Normal or Tolerant.
Connect lines
How near the ends of a Straighten pencil line must be to be joined into a closed shape.
Pen
Show pen preview draws the next segment to the cursor before you click; Show solid points draws the pen's anchors filled.

Keyboard shortcuts

Choose Edit › Keyboard Shortcuts (Ctrl+Alt+Shift+K) to see every menu command and tool with its key. Type in the search box to find a command by name or by key. Select a command, click in the Shortcut box and press the keys; a key another command had is taken from it, and the dialog says which. Keys given to two commands show in red, and keys you have changed in bold. Default gives one command its own key back, and Reset All gives every command its own.

Save your keys as a named set with Save As and switch between sets from the Set list. Export and Import pass a set to another machine as a JSON file.

The Set list starts with two built-in sets. Phoenix Defaults gives every command its own key. Animate Standard gives Animate's standard keys to the commands Phoenix shares with Animate: for example Redo is Ctrl+Y and Remove Transform is Ctrl+Shift+Z, the Flow Brush (Animate's Fluid Brush) is B and the Nib Brush (Animate's Classic Brush) is Shift+B. A key the set gives one command is taken from any command that had it.

Import also reads a shortcut set saved from Animate, as XML or as a text list of commands and keys. Each command is matched to Phoenix's by its menu and name, or by Animate's name for it where Phoenix names it differently. Keys written for macOS (Cmd, Option) become Ctrl and Alt. Phoenix then says how many were matched and lists the commands it does not have.

From the command line, Phoenix shortcuts lists every command with its key, and Phoenix shortcuts --defaults lists Phoenix's own.

Settings saved in the document

Some settings belong to a document rather than to Phoenix, so they travel with the file: the stage size, frame rate and color, ruler guides, Snap to Guides, Snap to Objects, and the swatches.

Where settings are stored

On Windows, Phoenix keeps its settings in the registry under HKEY_CURRENT_USER\Software\Phoenix. On macOS, they are in Phoenix's preferences file in ~/Library/Preferences. Auto-save recovery copies are kept in Phoenix's local application data folder. Removing these resets Phoenix to its first-run state.
