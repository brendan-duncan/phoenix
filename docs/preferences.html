Settings and preferences

Phoenix has no separate preferences window yet. Instead, it remembers the choices you make as you work, and you change a setting where you use it.

What Phoenix remembers

SettingWhere you change it
Recent files (the last ten)File › Open Recent and the start screen
Whether the start screen appearsShow at startup on the start screen
Auto-save intervalFile › Auto-Save
Window size and panel layoutArrange the window and panels; they are restored next time
Outliner shown or hidden, and its widthView › Outliner, or drag its edge
Each tool's settings, including each brush'sThe Tool tab of the Properties panel
Onion skin range, mode, opacity and colorsView › Onion Skin Settings
High-quality anti-aliasing, Snap to PixelsThe View menu
Last New Document size and frame rateThe New Document dialog
Symbol type and registrationThe Convert to Symbol dialog
Last export format and the ffmpeg locationThe Export Movie dialog
Saved custom eases and motion presetsThe Custom Ease dialog and Motion Presets panel
Last folders used to open and importThe file dialogs

Settings saved in the document

Some settings belong to a document rather than to Phoenix, so they travel with the file: the stage size, frame rate and color, ruler guides, Snap to Guides, Snap to Objects, and the swatches.

Where settings are stored

On Windows, Phoenix keeps its settings in the registry under HKEY_CURRENT_USER\Software\Phoenix. On macOS, they are in Phoenix's preferences file in ~/Library/Preferences. Auto-save recovery copies are kept in Phoenix's local application data folder. Removing these resets Phoenix to its first-run state.
