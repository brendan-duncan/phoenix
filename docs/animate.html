Coming from Animate

If you know Adobe Animate or Flash, you already know most of Phoenix. This page covers the differences, so you can get straight to work.

What carries over

  • Your files. Phoenix opens FLA and XFL files, and binary FLA files from Flash MX 2004 to CS4 (a CS4 file can open with its drawing objects missing), and saves FLA files that Animate opens again. TLF text opens as classic text, as Animate converts it. Data Phoenix does not use itself, such as ActionScript, is kept as it was. Publish settings are read and written by Phoenix's own Publish, and the settings it does not use are kept.
  • The drawing model. Merge and object drawing, primitives, groups, and how strokes and fills interact all behave as you expect.
  • The timeline. Layers, folders, keyframes, classic, shape and motion tweens, eases, masks, guides and motion guides, and layer parenting. In Layer Properties, Follow parent's Scale, Skew and Flip can each be turned off for a child layer; see Layer parenting.
  • Symbols. Graphics, movie clips and buttons, editing in place, looping options, color effects, blend modes and filters. 9-slice scaling draws on the stage and in exports, also on rotated or skewed instances and those with color effects, filters or blend modes.
  • Your muscle memory. Tool keys, F5 to F8, the frame and arrange shortcuts, and the modifier keys while drawing are the same.

What works differently

  • Native format. New documents save as .phx, which opens much faster. Use Save As to write an FLA whenever you need one, or choose FLA files or XFL folders under File › Default Save Format.
  • Movie clips on the stage show their first frame while you edit and scrub; their animation plays while the document plays and in exports.
  • Scripts run in Test Movie. ActionScript is saved with the file. Control › Test Movie runs ActionScript 1 and 2, frame scripts and button handlers alike, and ActionScript 3 frame scripts with mouse, keyboard and enterFrame listeners; ActionScript 3 classes are not run yet. Playback on the stage and exports follow only the simple calls in frame scripts (stop(), play() and the gotos), with Control › Enable Simple Frame Actions on. See Frame scripts.

What Phoenix adds

Ink Brush
A brush with a stabilizer for steady lines, an adjustable pressure response and tilt that broadens the line, for clean inking.
Time Scrub tool
Drag across the stage to move through time.
Outliner
The whole document as a tree, down to individual paths.
Phoenix documents
A faster, more robust file format with room to grow. See The Phoenix format.
Crash recovery
Regular recovery copies, offered back after a crash.
Reference video
Import video straight onto a guide layer to animate over.
Shareable eases and presets
Export custom eases as JSON, and import Animate's motion presets.
Rigging
An X-sheet, pegs, master controllers, curve and envelope deformers, and function curves for any layer property. See Rigs and motion.
Ink and paint
Line and color art on separate layers, linked palettes that recolor a whole document, and tone, highlight and glow layers. See Ink, paint and palettes.
Compositing output
Line, color and matte passes, multi-layer EXR, and ProRes video. See Compositing passes.
Render queue
Renders lined up and run in the background while you work. See Render queue.
Studio pipeline
Split an episode into shots, link rigs to master files and update every shot, and leave review notes on frames. See Shots, assets and review.
Command-line rendering
Render, convert, check and repair, compare versions and process whole folders without opening a window. See Command line and Version control.
Free and open source
On Windows and macOS, with Linux on the way.

Not in Phoenix yet

These Animate features are not available yet. Files that use them still open, and the data is kept when you save.

  • 3D rotation and translation are drawn and edited in Phoenix, but kept as Phoenix's own settings: Animate shows such clips flat.
  • Spring simulation on bones (springs are kept). Armatures, boned shapes and warps play, and the Asset Warp tool turns artwork into a new puppet; Animate also stores rendered images of a puppet, which Phoenix does not make, so check a puppet made in Phoenix in Animate before relying on it there.
  • Animate's built-in art and pattern brush library. Phoenix's Paint Brush draws art and pattern brushes made from your own graphic symbols; Animate shows those strokes as plain lines.
  • Running ActionScript 3 class files (a document class, .as files) and HTML5 Canvas JavaScript. ActionScript 1 and 2, and ActionScript 3 frame scripts with their event listeners, run in Test Movie.
  • Setting up and moving 9-slice guides. Guides already in the file work.
  • HTML5 Canvas documents, and publishing to AIR or projectors. Published SWF movies have no sound or ActionScript.
