Keyboard shortcuts

Phoenix uses the keys most 2D animators already know. On macOS, use Cmd where this page says Ctrl, and Option for Alt. Change them in Edit › Keyboard Shortcuts; only Object Drawing (J), the next-tab and scene keys, Delete, and the keys you hold while drawing are fixed.
