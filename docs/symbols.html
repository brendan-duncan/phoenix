Symbols

Symbols and instances

A symbol is artwork you make once and use as often as you like. Each use is an instance. Change the symbol and every instance changes with it; move, scale, tint or animate an instance and the symbol stays the same.

Symbol types

TypeBest forTimeline
GraphicCharacter parts, props, lip-sync mouths: anything animated in step with the main timelinePlays in sync with the timeline it is placed on, so you see its animation as you scrub
Movie ClipSelf-contained loops, and anything that needs filters or 3D rotationPlays on its own clock, independent of the timeline it is placed on
ButtonInteractive content for players that support itFour frames: Up, Over, Down and Hit
Note

On the stage, a movie clip shows its first frame while you edit and scrub. Its animation plays when you export. Use graphic symbols when you want to see the animation in the editor.

Create a symbol

From artwork on the stage

  1. Select the artwork.
  2. Choose Modify › Convert to Symbol... (F8), or right-click it and choose Convert to Symbol.
  3. Give the symbol a name, choose its type, and click a square in the Registration grid to set where its origin will be. The origin is the point the instance rotates and scales around by default.

The selected artwork is replaced by an instance of the new symbol. Phoenix remembers the type and registration you chose for next time. Names must be unique in the library.

From scratch

Choose Insert › New Symbol... (Ctrl+F8), name it and pick its type. Phoenix opens the empty symbol so you can draw in it. It is added to the library; drag it onto the stage to use it.

Edit a symbol

There are two ways to open a symbol:

Edit in place
Double-click an instance on the stage, or choose Edit › Edit in Place. The rest of the stage stays visible but dims, so you can draw the symbol in context.
Edit on its own
Choose Edit › Edit Symbols (Ctrl+E), double-click the symbol in the library, or pick it from the Edit Symbols list at the right of the edit bar.

Inside a symbol you have its own timeline and layers, and all the tools work as usual. A crosshair marks the symbol's origin.

To go back, double-click an empty part of the stage, click the Back arrow or a name in the edit bar, or press Ctrl+E (which reads Edit Document while you are inside a symbol). Symbols can contain other symbols, and the edit bar shows each level you have opened.

Instance properties

Select an instance to see its settings on the Object tab:

Instance name
For movie clips and buttons, a name that scripts can use to find the instance. It is in the header at the top of the tab.
Symbol and Swap...
The symbol this instance shows. Swap... replaces it, keeping the instance's position, transform and effects.
Type
Whether this instance acts as a graphic, movie clip or button, independent of the symbol's own type.
Position and Size
X, Y, width and height.
Color Effect and Display
Brightness, tint, alpha and blend modes. See Filters, blends and color effects.
Filters
Drop shadows, blurs, glows and more, for movie clips and buttons.

Looping for graphics

A graphic instance plays its symbol's frames in step with the timeline it is on. The Looping section controls how:

OptionPlays
LoopFrom the first frame to the end, then starts again
Play OnceTo the end, then holds the last frame
Single FrameHolds one frame, which is how you switch mouth shapes or hand poses
Loop ReverseBackward to frame 1, then starts again from the end
Play Once ReverseBackward to frame 1, then holds it
Ping PongForward to the end, then backward, and again

First sets the frame of the symbol to start from. Last sets where playing stops or turns around: the loops run between First and Last, and the Play Once options hold on Last. Leave Last at 0 to play to the symbol's end.

Display

The Object tab's Display section has the instance's blend mode, and for a movie clip or button, Visible: turned off, the instance is not drawn, though it stays on the stage for scripts. Reg X and Reg Y place the instance by its registration point rather than by the corner of its bounds.

The Frame Picker

When a symbol holds a set of poses, such as mouth shapes, the Frame Picker is the fastest way to choose between them. Open it from Window › Frame Picker, select a graphic instance, and click a thumbnail to show that frame. The list beside Create Keyframe sets the instance's looping option. Check Create Keyframe to put each choice on a new keyframe at the playhead, which makes lip sync a matter of stepping through the timeline and clicking. To key a whole line of dialogue from a recording at once, see Lip sync.

Swap Symbol

Modify › Symbol › Swap Symbol... lists every symbol with a preview. The current one is shown in bold. Pick another and click OK, or double-click it. Duplicate Symbol... makes a copy of the selected symbol to swap to, which is handy when one instance needs a variation.

Bitmaps swap the same way: select one or more bitmaps on the stage and choose Modify › Bitmap › Swap Bitmap..., or click Swap... in the Properties panel. The new bitmap takes the old one's place, scale and rotation.

Break apart an instance

Modify › Break Apart (Ctrl+B) replaces an instance with a copy of the artwork from the frame it shows, with its color effect applied. The symbol itself is not changed.

9-slice scaling

Symbols that use 9-slice scaling, such as panels and buttons, keep their corners crisp when stretched: only the middle sections scale. Phoenix draws 9-slice symbols correctly on the stage and in exports.
