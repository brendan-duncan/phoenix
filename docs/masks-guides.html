Masks and guides

Two special kinds of layer change how other layers are drawn: a mask shows the layers beneath it only through its shapes, and a guide holds artwork that helps you work but never appears in the finished animation.

Masks

A mask layer acts like a window. Wherever it has artwork, the layers masked by it show through; everywhere else, they are hidden.

Make a mask

  1. Put the artwork to be revealed on a layer.
  2. Add a layer directly above it and draw the window shape on it. Its color doesn't matter.
  3. Right-click the upper layer and choose Mask. The layer below becomes masked by it, and both are locked so you see the result.

To mask more layers with the same mask, drag them into place directly under the mask layer, or set their type to Masked in Layer Properties.

How masks behave

  • Only fills count. Strokes on a mask layer are ignored.
  • Transparency in the mask is ignored: a half-transparent fill masks just like a solid one, with a hard edge.
  • Masks can be animated. Tween or draw the mask frame by frame for wipes, spotlights and reveals.
  • On the stage, a mask masks only while its layer is locked. Unlock it to see and edit the mask's own artwork, with the layers under it shown whole; lock it again to see the result. Exports always mask.

Guide layers

Right-click a layer and choose Guide to turn it into a guide layer. Use guide layers for sketches, layout drawings, reference images and notes. They are drawn while you work but left out of every export.

Tip

Imported reference video goes onto a locked guide layer automatically, so it is there to animate over but never ends up in your render.

Motion guides

A motion guide moves an object along a path you draw.

  1. Make a classic tween of an instance.
  2. Add a guide layer above it and draw the path with the Pen, Pencil or Line tool.
  3. Drag the tweened layer under the guide layer so it becomes guided, or set its type to Guided in Layer Properties.
  4. At the first and last keyframes, place the instance on the path's ends. With Snap on in the Frame tab, it snaps onto the path.

The instance now follows the stroke between the keyframes. Check Orient to path in the Frame tab's Tweening section, on the tween's first keyframe, and the instance also turns as the path turns.
