The node graph

Phoenix's Node Graph composites a timeline's layers much as Harmony's node view composites a scene, with a few differences:

  • Layers come first. A timeline stacks its layers as usual until you create a graph for it, and the graph can be turned off again. In a graph, a Layer node takes one layer (or a folder) out of the stack, and Other Layers brings in all the rest, so a layer added later still shows.
  • Each timeline has its own. A symbol's graph goes wherever the symbol does, in every instance of it.
  • Rigging stays on the timeline. Pegs, parenting and bones are set on layers and in the X-Sheet, not as nodes; the graph is for compositing.
  • What you see. Each node shows a picture of its result, and its eye shows that node on the stage, as a Display node would.

Phoenix saves Phoenix documents (.phx), FLA files and XFL folders rather than Harmony scenes. What only Phoenix draws (deformers, effect layers, palettes) is kept in the file for Phoenix, and the rest opens anywhere FLA files do.
