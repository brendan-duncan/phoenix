Phoenix User Guide

Draw freely. Animate fast. Deliver every shot.

Phoenix is a free, open source 2D vector animation studio for Windows and macOS. Artists get expressive brushes and a timeline that feels familiar from the first frame. Production teams get FLA files that open and save back intact, a fast native format, and rendering you can script, so Phoenix fits into the pipeline you already run.

What you can do with Phoenix

Draw the way you draw

Brushes that answer to pressure and tilt, textured and bitmap brushes, a pencil that tidies your lines, and a pen for exact curves.

Paint or build

Let shapes cut and blend like wet paint, or keep every shape a clean, separate object. Switch whenever you like.

Build once, reuse everywhere

Turn artwork into symbols, edit them in place, and keep a library that grows with the show. Add filters, blends and color effects to any instance.

Bring it to life

Frame by frame or tweened: classic, shape and motion tweens, custom eases, onion skinning, masks, bones and lip sync.

Open the files you already have

FLA files old and new, and XFL folders, open as they are and save back to FLA with nothing dropped, so years of work come with you.

Deliver in any format

MP4 and ProRes, GIF, PNG and SVG sequences, compositing passes, sprite sheets, SWF and WAV. Render one shot, queue a batch, or script it from the command line.

Rig and stage big shots

Pegs, deformers, master controllers and function curves for rigs; an X-sheet and a multiplane camera for staging.

Built for production

Start from the animatic, break it into shots, share linked assets across them, collect review notes, and keep every file in version control.

How this guide is organized

The guide follows the way a project usually goes. If you are new to Phoenix, read these in order:

  1. Install and update: get Phoenix running on Windows or macOS.
  2. Your first animation: a short walk from a blank document to an exported video.
  3. The workspace: the panels, what each one is for, how to arrange them, and how to save layouts and themes.
  4. Merge and object drawing: why shapes cut, join and stay apart the way they do.

After that, use the sidebar or press / to search. The keyboard shortcuts page lists every key Phoenix uses.

About Phoenix

Phoenix is free and open source, and is developed in the open on GitHub. It keeps its own work in the Phoenix document format (.phx), which opens faster than FLA and has room for features FLA cannot store. You can save as FLA at any time. Everything Phoenix needs comes with it, including the video encoder, so there is nothing else to install.

Phoenix is under active development, and new tools and panels arrive often. Sections marked Planned describe work that is on the way but not in the current release.
