Phoenix User Guide

Draw, animate and ship your 2D vector work

Phoenix is an open source 2D vector animation app for Windows and macOS. It has the drawing tools, timeline and symbols animators already know, and it opens and saves Adobe Animate FLA files without losing anything.

What you can do with Phoenix

Draw with vectors

Pen, pencil, three brushes, shapes and primitives, with pressure and tilt from a tablet pen.

Merge or object drawing

Shapes that cut and join like paint, or shapes that stay separate objects. Your choice per stroke.

Reuse with symbols

Graphics, movie clips and buttons, edited in place, organized in a library, styled with filters and blends.

FLA files

Frame by frame, classic, shape and motion tweens, eases, onion skinning, masks and bones.

Work with FLA files

Open files from Animate and older versions of Flash, and save them so Animate opens them again.

Export anywhere

MP4 video, animated GIF, PNG sequences, single images, SVG and WAV, from the app or the command line.

How this guide is organized

The guide follows the way a project usually goes. If you are new to Phoenix, read these in order:

  1. Install and update: get Phoenix running on Windows or macOS.
  2. Your first animation: a short walk from a blank document to an exported video.
  3. The workspace: the panels, what each one is for, and how to arrange them.
  4. Merge and object drawing: why shapes cut, join and stay apart the way they do.

After that, use the sidebar or press / to search. The keyboard shortcuts page lists every key Phoenix uses.

Already know Animate?

Most tools, panels and keys work the way you expect. Coming from Animate lists the few keys that differ and what Phoenix adds.

About Phoenix

Phoenix is free and open source, and is developed in the open on GitHub. It keeps its own work in the Phoenix document format (.phx), which opens faster than FLA and has room for features FLA cannot store. You can export to FLA at any time.

Phoenix is under active development, and new tools and panels arrive often. Sections marked Planned describe work that is on the way but not in the current release.
