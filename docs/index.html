Phoenix User Guide

2D Vector Animation Software

Phoenix is an open source 2D vector animation toolset for Windows and macOS. It is designed to provide a familiar workflow for animators, with advanced production features, compatibility with Animate FLA files, and a focus on performance and stability.

What you can do with Phoenix

Draw with vectors

Pen, pencil, brushes, shapes and primitives, with pressure and tilt from a tablet pen.

Merge or object drawing

Shapes that cut and join like paint, or shapes that stay separate objects. Your choice per stroke.

Reuse with symbols

Graphics, movie clips and buttons, edited in place, organized in a library, styled with filters and blends.

Animate over time

Frame by frame, classic, shape and motion tweens, eases, onion skinning, masks and bones.

Work with FLA files

Open FLA files, XFL folders and older binary FLAs, and save back to FLA whenever you need to.

Export anywhere

MP4 and ProRes video, animated GIF, PNG and SVG sequences, compositing passes, sprite sheets, images, SWF and WAV, from the app, the render queue or the command line.

Rig and stage shots

Pegs, deformers, master controllers, function curves, an X-sheet and a multiplane camera.

Run a production

Animatics, shot breakdown, linked shared assets, review notes, and XFL folders for version control.

How this guide is organized

The guide follows the way a project usually goes. If you are new to Phoenix, read these in order:

  1. Install and update: get Phoenix running on Windows or macOS.
  2. Your first animation: a short walk from a blank document to an exported video.
  3. The workspace: the panels, what each one is for, how to arrange them, and how to save layouts and themes.
  4. Merge and object drawing: why shapes cut, join and stay apart the way they do.

After that, use the sidebar or press / to search. The keyboard shortcuts page lists every key Phoenix uses.

About Phoenix

Phoenix is free and open source, and is developed in the open on GitHub. It keeps its own work in the Phoenix document format (.phx), which opens faster than FLA and has room for features FLA cannot store. You can save as FLA at any time. Everything Phoenix needs comes with it, including the video encoder, so there is nothing else to install.

Phoenix is under active development, and new tools and panels arrive often. Sections marked Planned describe work that is on the way but not in the current release.
