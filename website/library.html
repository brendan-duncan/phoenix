Symbols

The library

Every symbol, image, sound and font a document uses lives in its library. The stage holds instances; the library holds the originals, so changing an item changes every place it is used.

The Library is a tab beside Properties in the panel dock (Window › Library, Ctrl+L). It always shows the library of the document whose tab is in front. From top to bottom it shows:

  • A preview of the selected item: a symbol's first frame, or the image. A symbol with more than one frame shows a Play button that runs it in the preview. Folders and sounds have no preview.
  • The number of items in the library, and the library menu (☰), which has the same commands as right-clicking the selected item.
  • A Search field. See Find and sort items.
  • The item list, with folders you can open and close.

What the list shows

ColumnShows
NameThe item's name, with an icon for its type. Hover over a name inside a folder to see its whole path, such as Characters/Bunny/head.
TypeFolder, Movie Clip, Button, Graphic, Bitmap, Sound, Font, Video or Embedded Video. A symbol kept in step with a master file reads (linked).
Use CountHow many times the document uses the item: instances on every timeline, bitmap fills, and sounds on keyframes.
LinkageThe class name (or identifier) a symbol is exported to scripts under. See Linkage.
Date ModifiedWhen a symbol was last changed, or when a bitmap was imported or last updated.

When the panel is narrow, scroll the list sideways to see the later columns, or drag the panel wider.

Use library items

  • Drag a symbol or bitmap onto the stage to place an instance of it, centered where you drop it.
  • Drag a sound onto the stage to attach it to the current frame, or onto a layer in the timeline to attach it there. See Sound.
  • Double-click a symbol to open it for editing. Double-click a bitmap, sound or video to see its properties.

Find and sort items

Type in Search to show only items whose names contain what you type, in upper or lower case. Folders that hold a match stay in the list and open to show it, and a folder whose own name matches shows too. Click the field's clear button, or delete the text, to see everything again.

Click a column heading to sort by it, and click it again to reverse the order. Items sort within each folder, folders among them. Use Count sorts by number, so sorting it puts unused items first; the other columns sort alphabetically. The list starts sorted by name.

Organize the library

Right-click an item for:

Rename
Also F2. Type the new name in the list. Every instance, fill and sound that uses the item follows the new name automatically. Names cannot contain /, which separates folders.
Duplicate
Makes a full copy of a symbol, named after the original with copy added.
Properties...
For a symbol, its type, linkage and 9-slice scaling; for a bitmap or sound, see Bitmap and sound properties.
Linkage...
Gives a symbol a class name for scripts. See Linkage.
Generate Sprite Sheet...
Lays the symbol's frames out on one image for a game. See Sprite sheets.
Link to Master File...
Keeps a symbol in step with the same symbol in another file. Once it is linked, the menu reads Change Master File... and adds Update from Master and Unlink from Master, and the library menu has Update All Linked Items. See Linked shared assets.
Delete
Removes the selected symbols and bitmaps (also Delete). With several selected, it reads Delete 3 Items. If a symbol is still in use, Phoenix says how many times and asks before deleting it along with its instances. A bitmap that is still in use is kept, and Phoenix says so.
Copy, Paste
Copy items here and paste them into another open document's library. See Libraries of other documents.
New Symbol...
Makes a new symbol in the selected folder. Insert › New Symbol puts it there too.
New Folder
Adds a folder inside the folder you clicked, or in the folder that holds the item you clicked, named Untitled Folder 1 (rename it straight away with F2).
New Font...
Adds a font symbol. See Font symbols.
Expand All Folders, Collapse All Folders
Opens or closes every folder at once.
Select Unused Items
See Unused items.

Sounds, font symbols and folders cannot be deleted from the Library panel. All other library changes can be undone, each as one step.

Symbol Properties

Right-click a symbol and choose Properties... to change, in one step you can undo:

Type
Movie Clip, Button or Graphic. See Symbol types.
Class
The symbol's linkage class name; leave it empty for none.
Enable guides for 9-slice scaling
Turns on 9-slice scale guides. See 9-slice scaling.

Folders and moving items

Drag an item or a folder onto a folder to move it inside, or onto empty space to move it to the top level. Items move one at a time. Moving or renaming a folder takes everything inside it along, and every symbol instance, bitmap fill and sound that uses those items is updated to match. If a name is already taken in the folder, Phoenix refuses the change and explains why in the status bar.

Folders can hold folders. Phoenix remembers which folders you left open while you work, and Search opens folders to show what it finds.

Tip

Keep a folder per character or prop, and name symbols by part (head, arm_L, mouth_O). A tidy library makes swapping symbols and finding parts in the Edit Symbols list much quicker.

Unused items

Over time a library collects items nothing uses: imported pictures you replaced, symbols you swapped out. Right-click and choose Select Unused Items. Phoenix clears the search, selects every symbol and bitmap nothing in the document uses, opens the folders that hold them, and the item count reads how many it found, or Every item is used. Then press Delete to remove them all at once, as one step you can undo.

An item counts as used when a scene shows it: an instance, a bitmap fill or a keyframe sound on a scene's timeline, or inside a symbol that is itself used. A symbol with linkage counts as used too, since a script may create it. So an item used only inside an unused symbol is selected along with that symbol, even though its Use Count is above 0.

Linkage

Scripts create symbols from the library by their linkage: the class name a symbol is exported under. Right-click a symbol and choose Linkage..., then type a class name, such as Ball; leave it empty for no export. The name shows in the Linkage column, and Symbol Properties sets the same name under Class.

A symbol with a class name is exported for ActionScript. ActionScript 3 makes one with new Ball(), ActionScript 1 and 2 with attachMovie(), and HTML5 Canvas pages with new lib.Ball(). See ActionScript and JavaScript.

Setting linkage in Phoenix gives the symbol a class name only. FLA files you open keep the linkage they were saved with, including identifiers, base classes and the linkage of bitmaps and sounds, and Phoenix saves it back unchanged; but in the Library panel only a symbol's class name can be set, and setting it replaces an identifier or base class the symbol had. Scripts can set the rest; see Scripting. Sharing library items between movies at run time is not available.

Bitmap and sound properties

Right-click a bitmap for:

Properties...
Shows the bitmap with its source file, size and when it was imported. Allow smoothing draws it smoothly when scaled or turned. Compression (Photo or Lossless) and Quality are kept for publishing. Update reads it again from its file, and Import... replaces the image with another file, keeping every use of it. See Bitmap Properties.
Update
Reads the selected bitmaps again from the files they were imported from, after you change them in another program.
Edit With...
Opens the bitmap in an image editor you choose (Phoenix remembers it). Each time you save in the editor, Phoenix takes the change, as a step you can undo. See Keep bitmaps up to date.

A sound's Properties... show its format and length, with Play and Stop to hear it. A video's properties say whether it is embedded or linked, its size, frame rate and the file it came from; Phoenix keeps video items from FLA files but does not play them (see Reference video).

Font symbols

A font symbol carries a font, or the characters of it you need, with the document, so dynamic and input text look the same wherever the movie plays, even where the font is not installed. Right-click the library and choose New Font...: name it, pick the font and its style, and tick the characters to embed (uppercase, lowercase, numerals, punctuation, basic Latin), adding any others in Also.

To set text in a font symbol, select the text and choose Use for Selected Text from the symbol's right-click menu. Font Properties... changes it later; renaming it keeps the text set in it.

Libraries of other documents

To use items from another document, choose File › Import › Open External Library... (Ctrl+Shift+O) and pick an FLA, XFL or PHX file. Its library opens in a floating panel of its own, titled with the file's name, read-only: you can search and sort, but not rename or move anything, and it shows no preview. Open as many as you like; closing the panel lets the file go. Then:

  • Drag an item onto the stage to copy it into your document's library and place it.
  • Drag an item onto your Library panel to copy it without placing it.
  • Right-click items and choose Copy to Document to bring them into your library, or Copy to paste them into any open document's library later.

Between two open documents, right-click items in one library and choose Copy, switch to the other document's tab, and choose Paste from its library's menu. You can also drag items from one window's Library onto another window's stage or Library.

However they come, items arrive whole: a symbol brings the symbols, bitmaps and sounds it uses, and the folders they are in. When your library already has items of the same names, Phoenix asks how to resolve the conflict:

Don't replace existing items
Your items stay as they are, and what comes in uses them.
Replace existing items
Your items take the incoming contents, and everything that uses them shows the new ones.
Keep both
The incoming items get new names (Head copy), and what came with them uses those names.

Copying is a single step you can undo. To keep a symbol in step with the file it came from, link it to that file instead; see Linked shared assets. To bring in a whole document at once, its library and its main timeline as a movie clip, import it; see Other documents and movies.

Reusing work across documents

Phoenix has no separate assets panel. To keep things you use again and again, use the library tools above together with these:

A library document
Keep shared characters, props and backgrounds in one document and open it with Open External Library whenever you need them.
Linked shared assets
Link symbols to a master file, so updating the master updates every document that uses them. See Linked shared assets.
Templates
Save a document as a template to start new documents with its library. See Templates.
Motion presets
Save a motion to apply to other objects, in any document. See Motion presets.
Brush Library
Keeps paint brushes for every document. See Brush Library.
