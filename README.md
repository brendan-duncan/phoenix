# Phoenix

Phoenix is an open source vector animation app for Windows and macOS. It has the drawing tools, timeline and symbols animators already know, and it opens and saves Adobe Animate FLA files without losing anything.

![Phoenix](docs/assets/shots/hero.webp)

## Features

- **Drawing:** pen, pencil, brushes with pressure and tilt, shapes and primitives, with merge or object drawing.
- **Symbols:** graphics, movie clips and buttons, edited in place and organized in a library, with color effects, blend modes and filters.
- **Animation:** keyframes, classic, shape and motion tweens, eases, onion skinning, masks, guides and bones.
- **Files:** opens FLA and XFL files, including older Flash files, and saves FLA files that Animate opens again. Its own `.phx` format opens faster and has room for features FLA can't store.
- **Export:** MP4 video, animated GIF, PNG sequences, images, SVG and WAV, from the app or the command line.

## Download

Installers for Windows and macOS (Apple silicon) are on the [releases page](https://github.com/brendan-duncan/phoenix/releases/latest). Installed copies update themselves.
